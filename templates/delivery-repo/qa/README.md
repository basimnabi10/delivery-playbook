# qa/

**Owner:** the QA function (see `team.yml`). **Written by:** QA only, by pull request.

- `hub/` is client-safe: curated try-it prompts and the known-limitations register. QA curates the prompts, and the PM approves the client-safe wording.
- `internal/` is never rendered: the test suite, run results (pass rates stay internal), bug sheets as CSV (never a credentials tab), the release gate and test plans.

See `playbook/onboarding/repo-layout.md`.
