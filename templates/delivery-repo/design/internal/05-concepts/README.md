# design/internal/05-concepts/

**Written by** the designer (the PM or lead as backup), by pull request through `scripts/sync.py`. **Visibility** internal: never rendered on the Delivery Hub.

Early ideas before the real build in Claude Design: wireframes, first drafts, concept directions. One file per concept, copied from [`_template.md`](_template.md) and named after it (`dashboard-cards.md`).

Each file says what the idea was, where it lives (a link), whether it was kept or dropped, and why. A kept concept becomes a flow in `06-flows/`; note the flow id in the concept file so the trail is easy to follow.
