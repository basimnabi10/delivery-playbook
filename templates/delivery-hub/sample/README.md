# Sample project: Acme Portal

A fictional project, used three ways: as a worked example of every file in a delivery repo, as the fixture
that `scripts/selftest.py` builds from, and as the design reference for the Delivery Hub.

Build it and open the page:

```
python3 scripts/build.py --sample --out /tmp/sample-hub/index.html
```

Everything here is invented. Names, dates and figures do not come from any real project.
