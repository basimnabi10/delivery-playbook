# Function guides

One guide per function: project management, product management, design and QA. Each says what the function owns, what its preflight checks, and which artefacts it writes.

Status: planned. The project-management guide is written first (it owns the Delivery Hub), then product management. The design and QA guides follow once those are proven. Until then the agent gives design and QA a minimal preflight: what is stale, missing or unowned.
